# Animated To-Do App

A modern, responsive **To-Do List web app** built with **HTML, CSS, and JavaScript**. It features **animated UI**, **dark/light mode**, **localStorage persistence**, **task due dates**, and **filter/search functionality**.

---

## 🌟 Features

- Add tasks with a **title** and **due date**  
- Mark tasks as **completed** or **delete** them  
- Tasks that are **past due** are highlighted as **overdue**  
- **Filters**: All, Pending, Completed, Overdue  
- **Search bar** to quickly find tasks  
- **Dark/Light theme toggle** (saved in localStorage)  
- **Responsive design** for mobile and tablet  
- Smooth **animations** and hover effects for a polished UI  
- Tasks and theme are **stored in localStorage** and persist on reload
